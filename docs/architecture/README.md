# Architecture Decision Records

Index of ADRs for this repository. Each record captures a decision,
its context, and its consequences at the time it was made.

## Format

Each ADR contains: **Status** (Proposed | Accepted | Superseded by
ADR-xxx), **Date**, **Context**, **Decision**, **Consequences**.

Superseded ADRs are kept, marked, and linked to their replacement.
